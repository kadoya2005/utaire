# うたいれ（声 → MIDI）

マイクで歌う（またはしゃべる）と、音の長さ・高さ・歌詞が入った MIDI ファイルを作る Web アプリです。
できた MIDI は、OpenUtau にそのままドラッグして開けます。

## 使い方

1. 歌詞を**ひらがな**で入れる（のばす音は「ー」）
   - 打たなくても大丈夫です。「🎤 声で歌詞を入れる」で読み上げるか、録音のあとに「🤖 AIで歌詞を起こす」を押すと、声から歌詞が入ります。
2. 「● 録音」を押して歌う → 「■ 停止」
   - 録音のかわりに、音声ファイルも使えます。
3. ピアノロールで確認・手直しする
   - 音符をタップして選び、↑↓で高さ、「前とつなぐ」「半分に分ける」「削除」で数を合わせます。
4. 「MIDIを保存」を押す（スマホでは共有メニューが開きます）

## 声から歌詞を入れる機能について

| 方法 | しくみ | 向いていること |
|---|---|---|
| 🎤 声で歌詞を入れる | ブラウザの音声認識（Google / Apple のサーバーで処理。ネット接続が必要） | 歌詞を普通に読み上げて入れる |
| 🤖 AIで歌詞を起こす | ブラウザの中で動く AI（Whisper）。声は外に送らない。初回だけモデルを読み込む（「ふつう」約80MB、「軽い」約40MB） | 録音した声や音声ファイルから起こす |

- 聞き取った言葉は、辞書でひらがなに直してから入ります（初回だけ約17MBの辞書を読み込みます）。
- メロディーをつけて歌った声は、どちらの方法でも聞き取りにくいことがあります。まちがいは歌詞の欄で直してください。
- うまく聞き取れないときは、「診断表示」を開いて「記録をコピー」を押すと、原因を調べるための記録を取れます。
